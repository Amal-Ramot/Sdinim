# סדינים · עורך גיליונות ציונים

אפליקציית Next.js + React שמקבלת קובץ Excel של ציונים (למשל ייצוא „צפייה בציונים תקופתיים” מהמשו״ב) ומאפשרת:

- **ניקוי חכם בלחיצה** – הסתרת עמודות ריקות/קבועות ות.ז, ואיחוד עמודות של אותו מקצוע שמפוצלות לפי קבוצות.
- **עמודות** – גרירה להזזה (בטבלה או ברשימה), הסתרה, מחיקה, מיזוג, שינוי שם, מיון.
- **עריכת תאים** כמו בגיליון – לחיצה כפולה או הקלדה, ניווט בחיצים, Enter/Tab, ביטול וחזרה (Ctrl+Z / Ctrl+Y).
- **צביעת ציונים לפי טווחים** – תבניות מוכנות (רמזור, רק שליליים, הצטיינות) או טווחים וצבעים חופשיים, עם ספירה ומקרא.
- **הדפסה על דף אחד** – הטבלה מותאמת אוטומטית לגודל ולכיוון הדף (A4/A3/Letter) ונמתחת למילוי כל שטח ההדפסה.
- **ייצוא ל-Excel** עם הצבעים.

כל העיבוד מתבצע בדפדפן – הקובץ לא נשלח לשום שרת.

## הרצה מקומית

```bash
npm install
npm run dev
```

## פרסום ל-GitHub Pages

הוורקפלואו `.github/workflows/pages.yml` בונה ייצוא סטטי (`out/`) ומפרסם אותו.
ב-GitHub: **Settings → Pages → Source: GitHub Actions**.
